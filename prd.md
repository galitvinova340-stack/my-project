# PRD: Система мониторинга кадровых назначений в Костанайской области

**Версия:** 1.0
**Дата:** 16.09.2026
**Заказчик:** Галина Литвинова
**Статус:** к разработке

---

## 1. Цель и контекст

Продукт предназначен для оперативного получения информации о новых кадровых назначениях в Костанайской области (руководители уровня области, районов/городов, управлений, департаментов, отделов — лица, принимающие решения, ЛПР) с целью планирования встреч с потенциальными клиентами и выстраивания деловых отношений.

Ключевое требование бизнеса — скорость: информация должна поступать раньше, чем аналогичный контакт установят конкуренты, поэтому проверка источников выполняется несколько раз в сутки, а не раз в день.

## 2. Пользователи

- Основной пользователь: Галина Литвинова (инициирует и использует данные регулярно).
- Дополнительные пользователи: коллеги, имеющие доступ к общей папке на сетевом диске.

## 3. Функциональные требования

### 3.1. Этап 1 — сбор данных (мониторинг)

Система регулярно проверяет заданный набор источников на предмет публикаций о новых кадровых назначениях в Костанайской области и извлекает из найденных публикаций: ФИО, должность, орган/организацию, дату назначения.

Диапазон поиска по должностям: аким области, акимы районов/городов области, руководители областных управлений, департаментов, отделов, руководители профильных государственных предприятий и организаций квазигосударственного сектора региона.

### 3.2. Этап 2 — формирование карточки (досье)

Для каждого нового (ранее не зафиксированного) назначения система собирает дополнительную информацию из открытых источников и формирует карточку по модели данных (раздел 5), включая краткое резюме возможных тем для обсуждения при первом контакте.

### 3.3. Дедупликация

Перед добавлением новой записи система сверяет найденное назначение (ФИО + должность) с уже внесёнными в таблицу записями. При совпадении запись повторно не создаётся.

### 3.4. Хранение данных

Все карточки последовательно добавляются в существующий Excel-файл в общей папке:

```
C:\CKB\назначения\
```

Файл выступает единым источником данных для пользователя и коллег: используется для поиска, фильтрации, отслеживания статуса взаимодействия по каждому контакту.

**Технический риск:** запись в файл возможна только при наличии активного соединения с устройством, на котором смонтирована указанная папка (компьютер пользователя должен быть включён и подключено соответствующее приложение в момент запуска). При недоступности устройства обновление таблицы в этот заход не выполняется; см. раздел 7.

### 3.5. Уведомления

По результатам каждого прогона, при наличии новых записей, отправляется уведомление на электронную почту:

```
ga.litvinova@mail.ru
```

Уведомление отправляется независимо от доступности устройства с общей папкой (см. 3.4) и содержит краткий перечень новых записей (ФИО — должность) с указанием, что полные карточки требуют сверки/добавления в таблицу, если запись на этот раз не сохранилась автоматически.

## 6. Периодичность и расписание

Проверка источников выполняется 3 раза в сутки по времени Костаная (Asia/Qyzylorda, UTC+5):

- 08:00
- 13:00
- 17:00

## 7. Технические ограничения и риски

1. **Зависимость от доступности устройства.** Запись в Excel-файл на сетевом диске технически выполняется через компьютер пользователя. Если в момент запланированной проверки компьютер выключен или не подключён, обновление таблицы откладывается; необходимо предусмотреть логику дозаписи пропущенных находок при следующем доступном запуске без потери данных и без дублирования.
2. **Ограниченный охват Telegram/соцсетей.** Стандартный веб-поиск индексирует Telegram-каналы и посты в соцсетях выборочно. Для надёжного мониторинга требуется либо прямой доступ к API/клиенту (Bot API, Telethon и т.п.), либо периодическая ручная актуализация списка отслеживаемых каналов/страниц.
3. **Качество и достоверность данных.** Информация о карьере/контактах берётся исключительно из открытых источников; при отсутствии официального подтверждения запись помечается статусом «требует проверки» и не выдаётся как окончательный факт.
4. **Устаревание списка источников.** Официальные каналы конкретно акимата Костанайской области в Telegram на момент составления документа не подтверждены — источником по этой позиции остаётся официальный сайт (kostanay.gov.kz).

## 8. Нефункциональные требования

- Отсутствие дублирования записей при повторных запусках.
- Устойчивость к временной недоступности отдельных источников (сбой одного источника не должен останавливать весь прогон).
- Работа с персональными данными — только в пределах уже опубликованной в открытых источниках информации.

## 9. Критерии приёмки

- При появлении новой публикации о кадровом назначении в Костанайской области система формирует карточку по модели данных (раздел 5) не позднее следующей плановой проверки (08:00/13:00/17:00).
- Новая карточка добавляется в Excel-файл по указанному пути без дублирования уже внесённых записей.
- На email отправляется уведомление с перечнем новых записей.
- Если назначение уже зафиксировано ранее, повторная карточка не создаётся и уведомление не отправляется.

## 10. Открытые вопросы для уточнения на этапе разработки

- Способ доступа к Telegram-каналам (API/клиент) — требует отдельного технического решения.
- Итоговый согласованный перечень отслеживаемых страниц в соцсетях (Facebook/Instagram), если требуется их включение.
- Формат дозаписи данных при недоступности устройства в плановое время (очередь, повторная попытка при следующем подключении, и т.п.).
